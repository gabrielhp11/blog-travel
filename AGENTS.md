# Orientações do projeto

Siga as regras permanentes em `.cursor/rules/project-delivery.mdc`, além de `README.md` e `docs/PAGE_PATTERN_REFERENCE.md`.

Para criação ou postagem nas redes sociais, leia também `docs/social/WORKFLOW.md` e o registro da campanha mais recente. Esse arquivo guarda o fluxo solicitado pelo usuário, incluindo a preferência por gerar novas artes no Gemini web e o escopo de suplementos.

O usuário pediu para sempre atualizar o GitHub ao concluir alterações neste projeto: valide, crie um commit e faça push normal para `origin`. Não use force-push. As páginas de oferta devem ter pelo menos três imagens relevantes e distintas, com identificação clara de ilustrações editoriais.
